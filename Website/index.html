Ollama Tool Support

Florde's smart capability detection enables tool use even for Ollama models without native tool support. Code editing, file operations, and shell commands work with any local model.

Your Privacy, Built In

Florde is designed from the ground up to keep your code and data under your control.

🛡

Zero-Cloud-Storage

Your code never touches our servers. All data — projects, chat history, settings — stays in a local SQLite database or JSON files inside the app directory on your machine.

🔒

Encrypted API Communication

When using cloud AI models (Claude, GPT, Gemini), your requests go directly from your client to the provider. No proxy, no middleman, no data leakage.

🧠

Local RAG

Your project's context — file structure, codebase index — is built locally. No code is ever uploaded for indexing. Ollama support means fully offline AI is always an option.

⚙

Smart Tool Detection

Florde probes each model's capabilities — tool support, context window — and falls back to text-based tool calls when native tool APIs aren't available. Works transparently with Ollama and local models.

Installation Guide

Get Florde running on your system in minutes

1. Download the Installer

Download the latest Windows installer (.exe) below.

Download for Windows

2. Run the Installer

Double-click the downloaded file and follow the setup wizard. Florde will be installed to your Program Files directory.

3. System Requirements

  • Windows 10 or later (64-bit)
  • 4GB RAM minimum (8GB recommended)
  • 500MB disk space
  • Internet connection for cloud providers
  • Ollama (optional) — for fully offline AI

4. Troubleshooting

"Windows protected your PC" warning

Click "More info" then "Run anyway". The app is not yet code-signed. This will be added soon.

1. Download the DMG

Download the latest macOS package (.dmg) below.

Download for macOS

2. Install

Open the .dmg file and drag Florde to your Applications folder.

3. Open Florde

The first time you open Florde, macOS may show a security warning. Go to System Preferences > Security & Privacy and click "Open Anyway" to allow Florde to run.

1. Download AppImage

Download the latest AppImage below.

Download for Linux

2. Make Executable

chmod +x Florde-*.AppImage

3. Run

./Florde-*.AppImage

Alternatively, install via your package manager (community packages available for Arch, Fedora, Ubuntu).
