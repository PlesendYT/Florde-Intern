# Website — Showcase

**Kategorie:** 8. Website - Content | **Feature:** 8.6

## Ziel
Eine Showcase-Seite, die zeigt, was Benutzer mit Florde gebaut haben.

## Inhalt
- 6-12 Example-Projekte mit:
  - Projektname
  - Kurzbeschreibung (1 Satz)
  - Screenshot (Platzhalter)
  - Tags: "Web App", "CLI Tool", "Python", "React", etc.
  - Link zum GitHub-Repo (optional)

## Layout
- Grid: 2 Spalten Desktop, 1 Spalte Mobile
- Jede Card: Bild oben, Text unten
- Hover-Effekt: leichter Scale + Shadow
- "Submit your project" Link am Ende

## Implementation
- Section in `index.html` (oder neue Seite)
- Daten als statisches Array in `script.js`
- Screenshots: Platzhalter via `https://via.placeholder.com/600x400` oder CSS-Gradient
- Nach dem Launch: Community-Projekte per Formular sammeln
