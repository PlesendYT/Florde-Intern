The task router assigns work to the best model

  • 01

    Manual Mode

    You assign a provider per task type — generate, explain, review, refactor, test, document, plan — yourself.

  • 02

    Automatic Mode

    The router checks each connected model's capabilities (coding, reasoning, speed) and picks the best match for the task.

  • 03

    Fallback Dialog

    If no suitable provider is found, Florde asks instead of forcing a bad choice.
