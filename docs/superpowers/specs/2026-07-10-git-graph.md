# Git Graph / Branch Visualizer

**Kategorie:** 4. Git | **Feature:** 4.2

## Ziel
Visuelle Darstellung des Git-Branch-Graphen mit Commit-Historie, Branch-Namen und aktueller Position (HEAD).

## UI
- Neuer Tab "Graph" im Git-Panel
- Canvas/HTML-basierte Darstellung des Commit-Graphen von links nach rechts
- Jeder Commit als Punkt, Branches als farbige Linien
- HEAD-Marker, current-branch-Marker

## Daten
- `git log --graph --oneline --all --decorate` parsed die Text-Graph-Darstellung
- Oder: `git log --all --format="%H %P %s %d"` für strukturierte Daten
- Frontend zeichnet den Graph basierend auf Parent-Referenzen

## Interaktion
- Hover über Commit zeigt Message + Datum + Author
- Klick auf Commit zeigt Detail-Info (Diff zu Parent)
- Mausrad zoomt (falls nötig)

## Implementation (simpel)
- Parse `git log --all --format="...%H|%P|%s|%an|%at|%d..."` in structured array
- Zeichne via Canvas 2D API: Branches als farbige Pfade, Commits als Kreise
- Branch-Farben aus fester Palette (max 10, ab 11. Branch Wiederverwendung)
