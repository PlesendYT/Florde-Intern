Features

One environment for your entire workflow

Florde bundles terminal, git, docker, browser, and AI agent tools into one app — the agent has direct access to everything instead of jumping between windows.

Core Tools

Built-in development tools

Integrated Terminal

Real shell via node-pty and xterm.js, up to four splits, multiple terminal instances, project-relative working directory, and real-time data streaming.

Git Integration

Init, clone, push, pull, branch management, real merge, commit with status, diff view, blame, history, git graph, and commit search.

Docker Management

Container status, start, stop, restart, and logs. Image list, docker info, and docker-compose control via a tab interface.

Built-in Browser

Electron-based browser with navigation, back/forward/reload, JavaScript evaluation, and screenshots — controllable by the agent.

AI Agent

Tools the agent uses itself

Task Router

Routes tasks by type — coding, planning, vision, image generation — to the best model. Manual and automatic mode with fallback dialog.

Skills System

Reusable AI workflow templates. Create, import, export, and trigger skills with slash commands in chat. 4 built-in skills included.

RAG Knowledge Base

Chunk-based code indexing for retrieval-augmented generation. Auto-reindex, search, and configurable chunk sizes.

Execution Manager

Decomposes goals into steps and executes them sequentially. Queue, progress tracking, cancel, and execution history.

Tool Permissions

Per-tool ask/allow/deny rules. Auto-accept toggle with exception list for shell, file writes, git, and web access.

Audit Log

Logs every AI action — file reads, writes, commands, API calls — with type, status, and date filtering. AI-powered natural language search.

Organization

Keep your project on track

Todo List

Per-project task management with add, toggle, delete, filter, and clear done. Persisted in localStorage.

Notes

Per-project markdown notes with editor and live preview toggle. Create, save, and remove notes.

Decision Log

Record architectural decisions with title, date, reasons, and alternatives. Accepted and rejected options tracked per project.

Time Tracking

Session-based time tracking with start/stop timer and daily totals. Persisted in localStorage.

Extensible

Plugins, MCP, and integrations

MCP & Plugins

Model Context Protocol over stdio, SSE, and WebSocket with tool discovery. Plugin marketplace with local upload and SuperPowers methodology tools.

Ollama Model Hub

Browse, search, and download Ollama models by category — Llama, Qwen, Mistral, Code, Embedding, Vision. Auto-polls for local models.

Customizable UI

5 themes (Dark, Light, High Contrast, Solarized Dark/Light), 4 layouts (Sidebar Left/Right, Top Bar, Floating), adjustable font sizes, and custom keyboard shortcuts.

Export ZIP

Export your entire project as a ZIP archive with one click.

Privacy First

Your code stays yours

Florde runs entirely on your desktop. No telemetry, no cloud storage, no data leaves your machine unless you choose a cloud provider.

Offline Mode

Block all internet access with one toggle. The agent works completely offline with local providers like Ollama, LM Studio, or llama.cpp.

Keychain Storage

API keys are stored in your OS keychain (Windows Credential Manager, macOS Keychain, Linux Secret Service) — never in plain text files.

Zero Cloud Storage

All code, chat history, and project data stays in local database files. Nothing is synced to any external server.

Connected

19 Connected Apps

Florde connects to the tools your project already uses — via MCP servers, APIs, and built-in integrations.
