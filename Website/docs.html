Documentation

Getting Started

Florde is an AI-powered development environment. To get started:

  1. Download Florde from the homepage
  2. Install using the installer for your platform
  3. Launch Florde and create a new project or open an existing one
  4. Configure an AI provider in Settings (Ollama, OpenAI, Anthropic, etc.)
  5. Start chatting with the AI to build your project

Chat Interface

Florde's primary interface is a chat panel where you interact with an AI assistant. The AI can read/write files, run terminal commands, and manage your project.

Writing Files

When the AI writes files, they appear in the Diff Viewer at the bottom of the chat panel. You can review changes before they are applied.

Code Execution

The AI can execute code in the terminal panel. Commands are run in a sandboxed environment for security.

Git Integration

Florde includes a full Git panel with:

  • Status — View changed files, stage/unstage changes
  • Commit — Write commit messages and commit with a single click
  • Branches — Create, switch, merge branches
  • History — Browse commit history with search
  • Graph — Visual branch graph showing all branches and merges
  • GitHub — Push, pull, and manage remotes

Terminal

The integrated terminal supports:

  • Split panes — Split horizontally or vertically for multiple terminals
  • Multiple shells — Each split runs its own shell process
  • Docker integration — View and manage containers, images, and Docker Compose

Docker

The Docker panel provides:

  • Containers — List, start, stop, restart containers
  • Images — List and manage Docker images
  • Compose — Manage Docker Compose projects with up/down/logs commands

Knowledge Base (RAG)

Florde can index your project files and use them as context for AI responses. Enable the Knowledge Base panel to:

  • Auto-index — Automatically index project files on open
  • Search — Search through indexed chunks
  • Context injection — Relevant code is automatically included in AI prompts
  • Configurable — Adjust chunk size, max chunks, include/exclude patterns

Keybindings

Customize keyboard shortcuts in Settings → Keybindings. Click any binding to record a new key combination.

Default shortcuts:

  • Ctrl+K — Open Command Palette
  • Ctrl+Shift+P — Toggle Notes Preview
  • F11 — Toggle Fullscreen
  • Ctrl+S — Save current note

Plugins

Florde supports a plugin system for extending functionality. Open the Plugins panel from the start screen or settings to browse and install plugins.

Troubleshooting

Ollama Connection Refused

If you see net::ERR_CONNECTION_REFUSED for localhost:11434, Ollama is not running. Start Ollama or configure a different provider.

Buttons Not Clickable

If titlebar buttons are unclickable, ensure the window frame is properly loaded. This can happen if the preload script fails.

Git Not Found

Ensure Git is installed and available in your system PATH.
